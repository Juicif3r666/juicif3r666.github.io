Privacy Policy

ODC Stream Package · last updated October 19, 2026

Who we are

The ODC Stream Package is a broadcast toolkit run by the caster of Orion Drift Competitive streams on their own computer. It is not a public service and has no servers of its own.

What we access, and why

If the YouTube channel owner chooses to sign in with Google, the package asks for permission to manage the channel's YouTube live streaming (Google scope https://www.googleapis.com/auth/youtube). It uses that permission only to:

  • create and update scheduled live events (title, description, start time, privacy setting) for matches the caster has claimed on oriondriftcompetitive.com;
  • list the channel's stream keys, so an event can be connected to the key the caster streams with;
  • read the channel's name, to show which channel is connected.

It does not read, change or delete videos, comments, subscribers, analytics or any other account data, and it never sees the owner's password - sign-in happens on Google's own page.

Where the data is kept

The sign-in key Google returns is stored only on the caster's own Windows PC, encrypted so that only that Windows user account can read it. A small list of the events created (match id, event id, title, start time) is kept on the same PC. Nothing is sent to us or to anyone else, and nothing is sold or shared.

YouTube and Google

This app uses YouTube API Services. By signing in you also agree to the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The channel owner can remove the package's access at any time at myaccount.google.com/permissions. The caster can also press "Sign out" in the package, which deletes the stored sign-in key from their PC.
