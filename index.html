ODC Stream Package

The ODC Stream Package is the broadcast toolkit used to stream Orion Drift Competitive matches on YouTube: OBS overlays, a control dock for the caster, and small helpers that run on the caster's own PC.

What it does with YouTube

When the channel owner signs in once with Google, the package can create and update scheduled live events on that channel for the matches the caster has claimed on oriondriftcompetitive.com - the title, description and start time - and read the channel's own stream keys so the events use the right one. It does nothing else with the account.
